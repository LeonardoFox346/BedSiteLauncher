# v1.0.2

## 新增

- **最近任务可结束应用**：长按任务卡或点右上角 × 结束该应用后台（Root 下执行 `am force-stop`，会停掉服务、广播与推送），并支持「结束全部」。
- **通用 Root 模块**（Magisk / KernelSU）：刷入后自动设为默认桌面，授予最近任务用量访问、通知使用权、无障碍锁屏，加入电池白名单；可选停用原生桌面及其多任务提供者。

## 改进

- 设置页新增「问题反馈 Issue」与「源码仓库」入口。
- 版本号改为读取应用实际版本（关于页、设置页底部）。
- 关于页排版重做：3×3 功能网格。

## 安装

1. 下载 `BedsideLauncher-1.0.2.apk` 安装。
2. 已 Root：下载 `bedside-launcher-module-v1.0.2.zip`，在 Magisk / KernelSU 中刷入并重启。
